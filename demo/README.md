# 产品演示页

## `index.html` — 产品介绍（分页演示）

20 页幻灯片，用于对外介绍和发布：前半段讲「一位导演，一群演员」这套编排方式和它解决了什么，中段起逐页插入真实界面截图佐证，最后是安装步骤。

翻页方式：

- 键盘 `→` `↓` `PageDown` `空格` 下一页，`←` `↑` `PageUp` 上一页，`Home` / `End` 跳到首尾
- 滚轮上下翻页，触屏上下滑动翻页
- 底部圆点直接跳转，右下角箭头逐页前后

页面是手写的，改文案直接编辑 HTML 即可。截图以普通 `<img src="assets/...">` 引用，本地直接打开就能看。

### 视觉

浅色科技风：冷白底加网格与渐变光斑，卡片用细描边和柔和投影分层，页码以大号浅色数字压在右下角。改主色只需要动 `:root` 里的 `--accent`、`--cyan`、`--violet`。

尺寸全部写成 `rem`，由 `:root` 的 `--ui` 驱动：1500px 起 18px，1800px 起 21px，2200px 起 25px，2800px 起 29px，3400px 起 33px。这样 2K、4K 屏放大的是整幅构图（间距、卡片、控件一起变大），而不是只有字变大。正文列宽固定占视口 80%，所以各分辨率下左右留白比例一致。

每一页入场有一段淡入上移。浏览器的合成器被节流时过渡可能停在中间帧，所以切换后 760ms 会补一个 `.settled` 类强制落定，正文不会留成半透明。

### 截图页

截图页用 `.slide.shot`，版式为「眉标 → 一句话标题 → 截图 → 图注」，截图高度吃满剩余空间。这类页面不显示右下角页码水印。

## `dist/DSH-Tavern-deck.html` — 单文件分享版

把十张截图内联成 base64，产出一个 759 KB 的 HTML。发给别人后双击即可，不需要附带 `assets/`：

```sh
python build.py
```

改完 `index.html` 或替换截图后重跑一次即可。

## 截图来源

十张截图拍自本机一次真实推演会话（「灰烬航路」范例，15 轮），插在对应章节里：

| 文件 | 用在哪一页 | 内容 |
|---|---|---|
| `01-conversation.jpg` | 一幕之内三人开口 | 旁白为引用块，台词带角色名 |
| `02-toolbox.jpg` | 悬浮球入口 | 七个面板的图标展开态 |
| `10-trajectory.jpg` | 独立调用的证据 | 每轮拆成导演 + 三位角色的多条记录 |
| `03-characters.jpg` | 角色卡即那套设定 | 描述、性格、场景、示例对话 |
| `04-worldbook.jpg` | 可见性在条目里选 | 指定角色可见 + 角色勾选 |
| `05-persona.jpg` | 玩家人设 | 当前生效中标记与全部字段 |
| `06-prompt.jpg` | 提示词编排 | 逐块来源、字数、启停开关 |
| `07-preview.jpg` | 装配预览 | 命中条目带可见性标签 + 最终 system |
| `08-usage.jpg` | 用量统计 | 501.2K token、缓存命中 12.1% |
| `09-tracker.jpg` | 剧情回顾 | 世界 / 你 / 角色三段摘要 |

拍摄时需要注入一段样式隐藏第三方悬浮挂件（`dsh-whale-widget` 的余额气泡），否则会挡住右下角：

```css
[class^="dshwv-"],[class*=" dshwv-"]{display:none!important}
```
