# 产品演示页

演示目录里有两个单文件页面，都不依赖服务器，双击即可离线打开。

## `index.html` — 产品介绍（分页演示）

十页幻灯片，用于对外介绍和发布：讲清楚「一位导演，一群演员」这套编排方式，以及它解决了什么。没有具体剧情，语言面向第一次听说这个插件的人。

翻页方式：

- 键盘 `→` `↓` `PageDown` `空格` 下一页，`←` `↑` `PageUp` 上一页，`Home` / `End` 跳到首尾
- 滚轮上下翻页，触屏上下滑动翻页
- 底部圆点直接跳转，右下角箭头逐页前后

页面是手写的，改文案直接编辑 HTML 即可，没有构建步骤。配色是浅色科技风：冷白底加网格与渐变光斑，卡片用细描边和柔和投影分层，页码以大号浅色数字压在右下角。改主色只需要动 `:root` 里的 `--accent`、`--cyan`、`--violet`。

尺寸全部写成 `rem`，由 `:root` 的 `--ui` 驱动：1500px 起 18px，1800px 起 21px，2200px 起 25px，2800px 起 29px，3400px 起 33px。这样 2K、4K 屏放大的是整幅构图（间距、卡片、控件一起变大），而不是只有字变大。正文列宽固定占视口 80%，所以各分辨率下左右留白比例一致。

每一页入场有一段淡入上移。浏览器的合成器被节流时过渡可能停在中间帧，所以切换后 760ms 会补一个 `.settled` 类强制落定，正文不会留成半透明。

## `index.screenshots.html` — 界面截图册

十张真实截图，每张配一句说明。用来展示实际界面长什么样，适合放在介绍页后面作为补充材料。

截图放在 `assets/*.jpg`，改完内容后重新生成：

```sh
python build.py
```

`build.py` 会把十张截图以 base64 内联进输出文件，产物约 680 KB。

## 截图来源

十张截图拍自本机一次真实推演会话（「灰烬航路」范例，15 轮），覆盖：

1. 对话推演 — 一幕内多人接话
2. 工具箱 — 七个工具入口
3. 角色卡 — 卡片编辑器
4. 世界书 — 可见性分组与角色勾选
5. 玩家人设 — 含角色设定栏
6. 提示词编排 — 双作用域编排
7. 装配预览 — 真实装配函数输出
8. 用量统计 — token 与缓存命中
9. 剧情回顾 — 自动生成的分段摘要
10. 轨迹视图 — 每轮的多次独立调用

拍摄时用注入的样式隐藏了第三方悬浮挂件（小鲸鱼），否则会遮挡界面。
