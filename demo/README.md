# 产品演示页

`index.html` 是单文件演示页，所有截图以 base64 内嵌，直接双击即可离线打开，不需要服务器。

## 重新生成

截图放在 `assets/*.jpg`，改完内容后重新构建：

```sh
python build.py
```

`build.py` 会把 `assets/` 里的十张截图内联进 `index.html`，输出约 680 KB。

## 截图来源

十张截图拍自本机一次真实推演会话（「灰烬航路」范例，15 轮），覆盖：

1. 对话推演 — 一幕内多人接话
2. 工具箱 — 七个工具入口
3. 角色卡 — 卡片编辑器
4. 世界书 — 可见性分组与角色勾选
5. 玩家人设 — 含角色设定栏
6. 提示词编排 — 双作用域编排
7. 装配预览 — 真实装配函数输出
8. 用量统计 — token 与缓存命中
9. 剧情回顾 — 自动生成的分段摘要
10. 轨迹视图 — 每轮的多次独立调用

拍摄时用注入的样式隐藏了第三方悬浮挂件（小鲸鱼），否则会遮挡界面。
