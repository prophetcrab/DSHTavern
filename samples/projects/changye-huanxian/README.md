# 长夜环线 —— 角色扮演流程测试项目

一个用于检验 DSHTavern 角色扮演模式全链路的较完整剧本：5 名角色、16 条世界书、两套提示词编排（角色 + 导演），以及一条分四层释放的悬疑主线。

## 用法

```bash
# 先把 DSHTavern 装进正在运行的 dsh web（默认 http://127.0.0.1:3080）
node samples/projects/changye-huanxian/install.mjs
```

脚本只调用宿主的 loopback 路由，做四件事：建酒馆工作区（同名已存在则复用）→ 清空并导入 5 张角色卡 → 覆盖世界书 → 写入角色/导演两套编排。结束时打印工作区 id、角色 id 与两套提示词的预览长度，方便直接对照。

安装完成后在网页侧栏进入「长夜环线」新建会话即可；宿主会按工作区 mode 自动绑定 `tavern-rp`。

## 项目结构

| 部分 | 规模 | 设计意图 |
|---|---|---|
| 角色 | 5 张 | 每人只掌握真相的一块碎片，且各有说话习惯与隐瞒方式 |
| 世界书 | 16 条 | 4 条常驻（世界底线、叙事口径、主线真相、导演须知）+ 12 条关键词触发 |
| 角色编排 | 12 块 | 改了用户人设、作者笔记、历史后指令三块的文本 |
| 导演编排 | 7 块 | 收紧了旁白长度、轮换限制，并强化了 JSON 输出要求 |

## 角色与信息差

| 角色 | 身份 | 掌握的信息 | 隐瞒方式 |
|---|---|---|---|
| 林见夏 | 夜班售票员 | 一张编号对不上的无主票根 | 说“我那年刚来”，用理票根掩饰 |
| 沈砚舟 | 副调度 | 三年前的改道单副本 | 只说“文件上都写着”，回避细节 |
| 白鹭 | 实习记者 | 旧地图上的归雾桥 | 主动抛信息换情报，藏不住好奇 |
| 周德海 | 末班车司机 | 那晚车多停过一次 | 只说“照规矩开” |
| 苏鹤 | 神秘乘客 | 全部真相（漆盒里的账本） | 不说假话，但省略；被逼近就沉默 |

## 主线与释放顺序

真相：三年前暴雨夜归雾桥站塌方封站，官方抹去站名；巡夜人陈守义失踪并被定性为擅离职守，他留下记录改道指令的账本。苏鹤是他女儿；沈砚舟在改道单上签过名。

设计好的线索阶梯是 **票根 → 旧地图 → 改道单 → 账本**。世界书把「主线真相」和「导演须知」都标成 `audience: director`，所以角色看不到全貌，只有导演握着完整剧本。

## 已观察到的行为

一轮玩家输入会触发的模型调用数等于「导演决策次数 + 该幕开口角色数」；实测首幕三人登场用了 3 轮导演调度，单轮对话里最多三次角色发言（`MAX_SPEECHES_PER_BEAT`）。

线索阶梯基本按设计走通了：追问“归雾桥”触发旧地图条目、再追问封站原因时，改道单线索由白鹭和沈砚舟先后吐出；问漆盒时苏鹤直接给出“旧账。我父亲的。锁着。钥匙不在我这儿。”——常驻的主线真相让她知道全部，关键词条目则补充了漆盒细节。

## 修复记录

实测 5 次对话、11 个导演回合中，2 个回合完全没有输出 JSON，另有 1 个回合虽输出 JSON 却把角色台词写进了 `narration`。这两种情况下原实现会把整段文本（含 `[白鹭]`、`[沈砚舟]` 标记和别人的台词）当成一条旁白写进 `stage.jsonl`，再由 `renderStage` 补一个前缀，形成 `[旁白] [旁白] …` 并污染后续所有角色的「舞台记录」。

`src/orchestrator.ts` 新增 `splitTranscriptShaped`，在 JSON 解析与纯文本兜底两条路径上都先识别 `[旁白]` / `[角色名]` 结构：旁白去掉标记后保留，第一个非旁白标签作为 `nextSpeaker`，标签之后的预写台词丢弃（角色本来就有自己的调用，重放会把同一段话上两次舞台）。已补 5 个测试，全部 155 个测试通过。

修复后实测同一剧情继续推进 3 个导演回合：其中 1 个回合仍是纯文本，但旁白已干净、说话人被正确路由，结构化分段恢复正常。

## 仍未解决

- **导演 JSON 合规率仍约 50–70%**。修复只保证失败时不完全崩坏，没有提高合规率。根因可能是推理等级或模型对长中文提示词里“只输出 JSON”的遵从度，值得试的下一步是把 `director-format` 块移到提示词最末（模型对末尾指令更敏感），或改用 tool-call 约束输出。
- **`inner` 只取首轮**。编排器只在 `turn === 0` 采纳导演的 `inner`，后续轮次写出的 `inner` 会被丢弃，多轮调度时世界状态可能落后于实际剧情。
- **`facts` 从不写入**。`writeWorld` 每次都用 `world.facts` 原样回写，导演没有写事实的通道，只有 `hidden` 在增长。
