# 04 酒馆外壳：创建后调整面板与工具箱（设计）

> 状态：草案 v0.2（工具箱首版已落地：会话标题栏触发 + 右侧抽屉 + 第一个工具）
> 依据：D001（工作区 + 专用界面，方案 A）、D003（单包 + 插件树）、D004（工作区标记）
> 范围：酒馆界面的外壳布局、创建/收编后的引导面板、工作区工具箱的位置与交互。不含聊天流、提示词编排内部、角色卡/世界书读取内部（见 03）。

## 已实现（首版）

- **工具箱**挂在**酒馆会话**上，而不是创建页：会话内有一个**可拖动的悬浮圆形图标**（工具箱 SVG，位置存在 `localStorage`，默认落在输入框左下侧的空档）；只有会话 cwd 属于酒馆工作区时才出现（`conversation.input.left` 注册一个不可见的探测行负责发布当前站点）。
- 点击悬浮图标弹出**只含工具图标与名称的 2×2 浮层**，不展示工具内容；再点某个工具图标才打开该工具的**子弹窗**（居中浮窗：标题栏 + 关闭按钮，背景点击 / Esc 关闭）。
- 第一个工具：**提示词编排**（已实现，含拖拽排序、启停开关、恢复默认、保存状态胶囊）；角色卡 / 世界书 / 设置暂为占位图标。
- 创建页（侧栏「酒馆」）只负责工作区创建/列表/收编，不再承载编排功能。
- 尚未实现：创建后的「调整面板」、工具箱的收起状态记忆、窄屏形态。

## 一句话

创建酒馆后先进入一个**可跳过的调整面板**（导入角色卡/世界书、做基础设置）；进入酒馆工作区后，所有管理功能都收在右侧的**工具箱**里，用竖排图标切换管理面板，第一个是提示词编排。

## 页面结构（候选）

```text
酒馆工作区
┌───────────────────────────────────────────┬──────┬─────────────────┐
│                                           │ 工具 │  管理面板        │
│  主区域                                    │ 箱   │  （跟随图标）    │
│  （聊天流 / 空态 / 引导）                   │ [编] │  ……             │
│                                           │ [卡] │                 │
│                                           │ [书] │                 │
│                                           │ [设] │                 │
└───────────────────────────────────────────┴──────┴─────────────────┘
```

- **工具箱**：固定在右缘的窄图标栏（图标 + tooltip），只负责「切换当前管理面板」。
- **管理面板**：在工具箱左侧打开/收起，宽度可调或固定；复杂功能（如提示词编排）也可以整页显示，由该功能自己决定。
- **主区域**：酒馆聊天/角色空间的最终位置；v1 先放空态与引导，不阻塞管理功能。

## 创建/收编后的调整面板

流程：

1. 侧栏「酒馆」→ 新建酒馆（名称 + 目录）→ 创建目录、写标记、注册工作区（现有实现）。
2. 创建成功 → **自动进入「酒馆调整面板」**。
3. 面板内容是分步/分区（候选：角色卡、世界书、基础设置、完成），每步都可以先跳过。
4. 点「完成」或「稍后设置」→ 进入酒馆工作区；之后仍可从工具箱再次进入同一面板。

行为约定（候选）：

| 场景 | 行为 |
|---|---|
| 新建酒馆成功 | 打开调整面板 |
| 收编已有工作区 | 同样打开调整面板（工作区已存在，只是补资料） |
| 跳过 | 不创建任何资料；工作区显示空态引导 |
| 面板内保存 | 每步立即写入工作区文件（sidecar），没有「暂存草稿」 |
| 再次进入 | 工具箱里的对应图标（角色卡/世界书/设置）直达；或从酒馆列表进入 |

形态候选（待定）：

- **A 模态**：覆盖在主区域上的对话框，带步骤条；轻量、不打断「创建完成」的上下文。
- **B 页面**：创建后直接进入一个独立设置页，完成后切回工作区；空间大，适合角色卡导入。
- **C 右侧面板引导**：直接打开工具箱对应的面板；与后续管理入口一致，但引导感弱。

## 工具箱图标（候选顺序）

| 顺序 | 图标/名称 | 面板 | 空态 | 依赖 |
|---|---|---|---|---|
| 1 | 提示词编排 | 装配顺序、模板、预算、检查器（先做空面板） | 「还没有可编排的内容」 | 03 / D002 |
| 2 | 角色卡 | 角色画廊、导入、详情 | 「导入第一张角色卡」 | 03 |
| 3 | 世界书 | 世界书列表、导入、条目预览 | 「导入或从角色卡拆出世界书」 | 03 |
| 4 | 设置 | 酒馆名称、默认模板、作者笔记、工作区信息（路径/tavernId） | — | D004 |
| 5 | 预留 | 后续工具按同一注册表追加 | | |

- 工具箱是**浏览器半自己渲染**的（在 `main[key=tavern]` 面板内），不使用 DSH 全局右侧栏，也不改 DSH 外壳。
- 工具项用本地注册表描述（id / label / icon / order / render / 空态），先用静态数组，等真的需要跨插件扩展再考虑服务化。
- 工具箱是否承担「工作区管理」（改名、取消标记、删除工作区）待定；也可以把工作区管理留在现有的酒馆列表里。

## 交互细节（候选）

- 点击图标打开对应管理面板；再次点击同一图标收起（toggle）。
- 切换到另一个图标只换面板内容，不重置主区域状态。
- 展开状态与当前面板按工作区记忆（浏览器本地存储或工作区 sidecar）——v1 可先只记「上次打开的面板」。
- 空态：面板为空时显示引导 + 主按钮（导入/新建）；主区域空态同步提示「从工具箱开始」。
- 窄屏：工具箱折叠为底部/顶部图标条，管理面板改为整页（具体断点待定）。
- 键盘/可访问性：图标有 tooltip 与 `aria-label`；面板切换保持焦点位置。

## 与现有实现的衔接

- 现有「酒馆」面板（工作区列表 + 新建/收编）保留，作为**入口页**：没有选中酒馆时显示列表；选中/新建后进入酒馆工作区外壳。
- 创建流程里「新建酒馆」表单可以继续复用，只是成功回调改为打开调整面板。
- 提示词编排先按你之前的要求做成空面板，挂为工具箱第一项。
- 角色卡/世界书面板依赖 03 的读取层；在读取范围没定之前，这两个面板可以先显示空态与「待实现」。

## 待定（需要讨论）

1. **管理面板的承载方式**：右侧可调宽度分栏 / 抽屉浮层 / 主区域整页切换？
2. **调整面板的形态**：模态（A）/ 独立页面（B）/ 直接开工具箱面板（C）？
3. **调整面板是否分步**：一页三区（角色卡、世界书、设置）还是向导式步骤条？
4. **工具箱位置**：右侧竖排（图示）/ 顶部标签 / 左侧；是否可折叠。
5. **工具箱是否包含工作区管理**（改名/取消标记/删除），还是留在入口列表。
6. **主区域与工具箱的联动**：切换管理面板时主区域保持聊天（分栏）还是管理面板占用主区域（整页）。
7. **状态记忆**：按工作区记住上次面板/展开状态，还是每次默认收起。
8. **移动端/窄屏**：工具箱形态与管理面板的降级方式。
