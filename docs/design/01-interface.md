# 01 交互界面（设计）

> 状态：草案 v0.5（面板交互与 2K 字号已适配）
> 依据：D001（已定，方案 A）、D002（路线 A 起步，待定稿）
> 范围：界面形态、进入/退出、工作区与会话映射。不含提示词内容、角色卡数据结构。

## 一句话

一个酒馆工作区 = 一个酒馆（内含多角色、多聊天、共享世界书与提示词模板）；进入该工作区时界面切换为酒馆面板，其中每个聊天是一条 DSH 会话，运行在 `tavern` preset 下。

## 概念映射

| 酒馆概念 | DSH 对应 |
|---|---|
| 酒馆 | 工作区（目录 + `.dshtavern/` 标记） |
| 聊天 | 会话（session） |
| 运行模式 | Agent Preset `tavern` |
| 角色卡 / 世界书 / 提示词模板 | 工作区目录内文件 |
| 酒馆界面 | 插件注册的 `main` 主面板 |

## 界面

```
┌──────────────┬───────────────────────────────────────────────┐
│ DSH 侧栏      │ 酒馆 · <名称>    [角色] [模型] [设置]          │
│ ┌ 酒馆入口    │ ┌─────────┬─────────────────────┬───────────┐ │
│ │ 酒馆列表    │ │ 角色列   │ 聊天流               │ 资料抽屉   │ │
│ └ 工作区      │ │ 角色卡   │ 头像 / 名字 / 气泡   │ 角色卡     │ │
│               │ │ 最近聊天 │ 输入栏               │ 世界书     │ │
│               │ └─────────┴─────────────────────┴───────────┘ │
└──────────────┴───────────────────────────────────────────────┘
```

- **侧栏**：DSH 原样保留，增加「酒馆」入口，用于打开酒馆面板、管理酒馆与聊天。
- **面板**：全宽页面，自带角色列、聊天流、资料抽屉；不显示工具调用、推理块、文件卡片。
- **空态**：角色画廊 + 新建角色 / 导入角色卡。
- **输入栏**：发送、重生成、继续；不出现工具选择、计划模式等编码控件。

## 创建与进入

1. 侧栏「酒馆」→ 新建酒馆：输入名称/位置 → 创建目录、写插件标记、注册工作区。
2. 点击酒馆工作区或其中会话 → 自动切到酒馆面板。
3. 新建聊天 → 在酒馆工作区创建会话（`agentPreset: tavern`）。
4. 打开普通工作区 → 自动切回标准对话界面。

## 模式绑定

- 酒馆工作区在插件侧登记默认 preset `tavern`。
- 客户端创建会话时显式传 `agentPreset`；宿主在 `session/created` / `agent/created` 兜底纠正，防止从 DSH 侧栏新建的会话跑成 standard。
- 自动切换后，用户手动切到标准视图按会话记忆，不反复抢回。
- 已有普通工作区可以显式「收编」为酒馆（写标记文件，需确认）。
- 侧栏工作区徽章 v1 不做；普通工作区完全不受影响。
