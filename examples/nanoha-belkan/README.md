# 奈叶 × 贝尔卡遗迹 — 范例酒馆

日式二次元轻小说风格的同人范例。以《魔法少女奈叶》的世界观为基底，聚焦「贝尔卡遗迹」这条线，并把《日月同错》巅峰期的高皓光作为玩家角色（用户卡）接入。可直接当作一场长局的起点。

## 内容规模

| 项目 | 规模 |
|---|---|
| 角色卡 | 1 张（高町奈叶），约 3000 字 |
| 世界书 | 20 条，约 9000 字 |
| 用户卡 | 1 张（高皓光·巅峰期），约 1500 字 |
| 可见性分布 | 公开 14 / 仅导演 6 |

奈叶卡自带描述、性格、场景、系统提示词与 4 组示例对话，并携带 2 条私有世界书条目。世界书全部使用 `all` / `director` 两种可见性，**没有** `characters` 可见性条目，因此导入后无需手工重选角色 id。

## 世界

世界由无数「次元世界」构成，时空管理局（TSAB）跨越次元维持秩序。米德芝尔达是总部所在的发达管理世界；地球是毫不知情的「管理外世界」。魔法靠体内的「魔力炉心」驱动，魔导师以魔导器为搭档展开术式。

而在这片广袤的次元之上，曾有一个叫**贝尔卡**的古文明。它以强大的魔法与武力统治辽阔疆域，最终在漫长的战乱中走向衰亡，留下的只有遍布各处的遗迹、沉睡的太古遗产，和一个无人解开的谜。

## 角色

**高町奈叶**（19）— 时空管理局航空战技教导队史上最年轻的教官，被敌人敬畏地称作「白色恶魔」。温柔、元气、坚信「先沟通、再战斗」；一旦决定，就会「全力全开」。魔导器「旭日之心」是一根会说话的红白法杖。

**高皓光**（巅峰期）— 玩家角色。来自「异界」的三真法门门主，被那个世界称为「无道极法魔君」，是近千年的术法巅峰。他的「术法」与「神通」不是魔力，而是操纵因果与时间的法则。

## 核心秘密（仅导演可见）

新发现的贝尔卡遗迹最深处，有一道连通「异界」的次元门。门的核心是一具失控的太古遗产，沉睡千年，直到高皓光穿越降临的那一天，才第一次「从另一侧」被唤醒。

门一旦完全开启，两个世界将彼此倾泻，次元震会撕裂整片次元。高皓光的到来，既是门开启的原因，也可能是关上门唯一的钥匙。

而时空管理局的高层，早已知晓「异界」的存在，却选择了封锁。奈叶接到的任务书上，只有一行字：「调查遗迹内的太古遗产失稳」。

## 用法

把两个 JSON 分别导入对应工作区：

- `characters.json` → 工具箱「角色卡」→ 导入（创建一张卡）
- `worldbook.json` → 工具箱「世界书」→ 导入（20 条）

用户卡（persona）没有导入导出端点，二选一：

- 直接把 `persona.json` 复制到目标工作区的 `.dshtavern/persona.json`（覆盖前请先备份，注意它管理的是「一整个库」，而非单张人设）；
- 或在「人设」界面新建一张，把 `personas[0]` 里的各字段逐段粘贴进去。

## 玩法提示

这个范例的张力来自「两个世界的错位」：

- 奈叶的世界里，一切都可以用「魔力」解释，而高皓光偏偏是一具「测不出魔力」的异类；
- 高皓光笃信因果，看求法者（≈这个世界里居高临下的存在）本能地反感，而奈叶偏偏是那种「绝不高高在上」的人；
- 管理局的任务书是干净的，真相藏在被涂黑的档案里——把「门」「异界」「次元波动」这些词摆到台面上，奈叶会开始察觉任务背后的异常。

玩家只要让高皓光试着理解「魔力」、也让奈叶试着理解「术法」，两个世界的裂缝就会一寸寸露出来。范例推演走的正是这条线。
