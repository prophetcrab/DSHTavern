# 奈叶 × 贝尔卡遗迹 — 范例酒馆

日式二次元轻小说风格的同人范例。以《魔法少女奈叶》的世界观为基底，聚焦「贝尔卡遗迹」这条线，并把《日月同错》巅峰期的高皓光作为玩家角色（用户卡）接入。可直接当作一场长局的起点。

## 内容规模

| 项目 | 规模 |
|---|---|
| 角色卡 | 10 张（7 名主角阵营 + 1 反派 + 2 怪物），存于 `characters/*.charc` |
| 世界书 | 24 条（公开 14 / 仅导演 10），存于 `worldbook.json` |
| 用户卡 | 1 张（高皓光·巅峰期），存于 `persona.json` |

每张卡都自带描述、性格、场景、系统提示词、示例对话与私有世界书条目。世界书全部使用 `all` / `director` 两种可见性，没有 `characters` 可见性条目，导入后无需手工重选角色 id。

## 世界

世界由无数「次元世界」构成，时空管理局（TSAB）跨越次元维持秩序。米德芝尔达是总部所在的发达管理世界；地球是毫不知情的「管理外世界」。魔法靠体内的「魔力炉心」驱动，魔导师以魔导器为搭档展开术式。

而在这片广袤的次元之上，曾有一个叫**贝尔卡**的古文明。它以强大的魔法与武力统治辽阔疆域，最终在漫长的战乱中走向衰亡，留下的只有遍布各处的遗迹、沉睡的太古遗产，和一个无人解开的谜。

## 角色（主角阵营）

**高町奈叶**（19）— 航空战技教导队最年轻的教官，被敌人敬畏地称作「白色恶魔」。温柔、元气、坚信「先沟通、再战斗」，一旦决定就「全力全开」。

**菲特·泰斯塔罗莎**（19）— 执务官，奈叶的搭档与家人。沉静认真，闪电系魔导师，会挡在薇薇欧前面。

**八神疾风**（19）— 夜天之书的主人、机动六课队长。温柔的统帅，把守护骑士当家人，与贝尔卡有斩不断的羁绊。

**希格诺** — 守护骑士之首，「烈焰魔剑」的主人。寡言的贝尔卡剑士，挡在所有人前面。

**维塔** — 守护骑士，「审判之锤」的主人。好胜嘴硬，第一个跳出来质问外来者。

**薇薇欧**（10）— 奈叶与菲特的女儿，圣王血脉继承者。能「听见」遗迹深处旁人听不见的声音。

**尤诺·斯克莱亚** — 无限书库的考古学者。知识担当，隐约知道管理局高层隐瞒了某些事。

## 反派与怪物

**艾尔维拉**（`elvira-gatekeeper`）— 「门之看守者」，古代贝尔卡最后一位圣王的残存意志。千年前自愿以灵魂为锁封门，孤独千年后执念扭曲，认定「打开门让两界合一，贝尔卡就能复活」。

**自律圣像**（`saint-idol-guard`）— 贝尔卡的自律守护兵器，三米高的白色铠甲巨人。只会执行「排除异物」的指令，胸口「圣核」是唯一弱点。

**因果之影**（`causal-shadow`）— 门失稳后泄漏出的异界之物，无定型的绿光轮廓，会「预取」你的动作、用回声唤你的名字。

## 核心主线（仅导演可见）

新发现的贝尔卡遗迹最深处，有一道连通「异界」的次元门。门核心是一具失控的太古遗产，沉睡千年，直到高皓光穿越降临的那一天，才第一次「从另一侧」被唤醒。

门一旦完全开启，两个世界将彼此倾泻，次元震会撕裂整片次元。封门的唯一办法，是「切断高皓光与门之间的因果共鸣」——代价是他可能永远留在这个世界，或就此消散。

时空管理局的高层早已知晓「异界」的存在，却选择了封锁。奈叶接到的任务书上，只有一行字：「调查遗迹内的太古遗产失稳」。

## 用法

- `characters/*.charc` → 工具箱「角色卡」→ 导入（每张卡单独导入一次）
- `worldbook.json` → 工具箱「世界书」→ 导入（24 条）
- `persona.json` 没有导入端点：直接复制到目标工作区的 `.dshtavern/persona.json`（覆盖前先备份），或在「人设」界面逐字段粘贴

## 玩法提示

这个范例的张力来自「两个世界的错位」与「一场关于守护的抉择」：

- 奈叶的世界里，一切都可以用「魔力」解释，而高皓光偏偏是一具「测不出魔力」的异类；
- 高皓光笃信因果，看求法者本能地反感，而奈叶偏偏是那种「绝不高高在上」的人；
- 艾尔维拉不是纯粹的恶，她只是爱着贝尔卡、爱到把自己锁进永恒里的人——她的执念，与薇薇欧身上被奈叶与菲特教会的「爱」与「家」，正面相撞；
- 管理局的任务书是干净的，真相藏在被涂黑的档案里。

玩家只要让高皓光试着理解「魔力」、也让奈叶试着理解「术法」，两个世界的裂缝就会一寸寸露出来。范例推演走的正是这条线。
