# 灰烬航路 — 范例酒馆

日式轻小说风格的异世界冒险范例。用于演示 DSH-Tavern 的全部内容能力，也可以直接当作长局的起点。

## 内容规模

| 项目 | 规模 |
|---|---|
| 角色卡 | 3 张，共 6121 字 |
| 世界书 | 19 条，共 5706 字 |
| 可见性分布 | 公开 13 / 仅导演 5 / 指定角色 1 |

三张卡各自有独立的描述、性格、场景、自带提示词和示例对话（每张 4 组），并各自携带 2 条私有世界书条目。

## 世界

三百年前一场「坠灰」把世界表面埋进数百米厚的灰里。幸存者逃上浮岛，靠燃烧浮石维持高度，靠一层薄薄的「航带」互相往来——那就是灰烬航路。

航路九段。第七段发生过坠落，第八段无人，第九段只存在于传说和几张旧航图上。

灰分四种：落灰、灰暴、沉灰、静灰。静灰之所以静，是因为有东西在那里。

## 角色

**缇亚·维尔纳**（17）— 银翼号领航员。嘴硬，怕黑，父亲七年前随船沉在第七段。右眼的翳让她能看见别人看不见的东西，但她学会了不看。

**格里芬·奥尔德**（60+）— 机械师，黄铜假肢。嘴上刻薄，行动上从不含糊。坠星之夜他在场，救下了缇亚，没能救下她的父亲。这件事他一个人扛了七年。

**塞拉菲娜·兰德**（22）— 圣厅巡礼骑士。虔诚到危险，也已经开始怀疑。右手永远戴着手套，手套下面是一道她自己不敢看的印痕。

## 核心秘密（仅导演可见）

坠星之夜不是灰暴。三艘船沉没，是因为银翼二号从灰云下捞上来一件「圣骸」。它在甲板上醒了，让所有人听见死去亲人的声音。缇亚的父亲是唯一没有回头的人——他把女儿塞进救生舱，然后调转船头撞了上去。

圣骸没有被摧毁。它沉回灰云，但在沉下去之前把一部分自己留在了三样东西上：银翼二号的残骸、缇亚右眼的翳、塞拉菲娜右手手套之下。

三样东西会互相吸引。这就是为什么银翼号七年没走第八段，却一直在这条航路上打转。

## 用法

把两个 JSON 分别导入对应工作区：

- `characters.json` → 工具箱「角色卡」→ 导入（创建三张卡）
- `worldbook.json` → 工具箱「世界书」→ 导入

注意：`worldbook.json` 里有一条 `visibility: "characters"` 的条目，`characterIds` 里写的是占位符。导入后需要打开那条条目，重新勾选它归属于哪个角色——角色 id 是每个工作区各自生成的，无法预先写死。

## 玩法提示

这个范例的关键在于三个角色的秘密彼此咬合，但谁也不知道全貌：

- 缇亚知道航图和右眼，不知道父亲最后做了什么
- 格里芬知道坠星之夜的真相，不知道缇亚的眼睛和塞拉菲娜的手
- 塞拉菲娜知道自己的印痕，不知道它从哪来

玩家只要把「七年前」「第七段」「印痕」这些词摆到台面上，三个人就会各自露出破绽。范例推演用的正是这条线。
